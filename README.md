# Group Call Bot

Минималистичный Telegram-бот для групп: по команде администратора периодически
упоминает участников **текущего чата**. Рядом в том же процессе поднимается
Flask-сервер (`GET /` → `Hello World`).

## Команды

| Команда | Описание |
|---|---|
| `/start` | краткая инструкция |
| `/startcall <интервал>` | запустить цикл, например `/startcall 10m` |
| `/stopcall` | остановить цикл в этой группе |
| `/call` | один цикл упоминаний прямо сейчас |

Интервал: число + `s`/`m`/`h` — `/startcall 30s`, `/startcall 5m`, `/startcall 2h`
(от 10 секунд до 24 часов). Управление доступно только администраторам группы
(включая анонимных админов).

Каждая группа независима: `chat_id → интервал + asyncio.Task`. Повторный
`/startcall` отменяет старую задачу и запускает новую.

## Упоминания

* участники разбиваются на сообщения по 5 человек;
* если есть `@username` — обычный текст, иначе настоящий HTML-mention через
  `tg://user?id=...`;
* между сообщениями пауза ~1.5 с; при `RetryAfter`/FloodWait бот ждёт указанное
  время и делает одну повторную попытку (без агрессивных ретраев).

## Важно про список участников

Telegram Bot API не позволяет получить полный список участников группы.
Поэтому бот запоминает пользователей, которые пишут в чат (а также вошедших и
вышедших), пока процесс работает. Если список пуст — бот сообщит об этом, а не
упадёт. Обходить ограничения API бот не пытается.

## Запуск

```bash
pip install -r requirements.txt

export BOT_TOKEN="123456:ABC..."   # токен от @BotFather
export PORT=8080                   # опционально, по умолчанию 8080

python main.py
```

Бот работает в группах; добавьте его в чат и дайте право отправлять сообщения.
В личке доступны только `/start`.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота (обязательно) |
| `PORT` | порт Flask (по умолчанию 8080) |

## Ограничения RunXBuild

Постоянного хранилища нет, поэтому:

* без SQLite / Redis / PostgreSQL / локальных файлов состояния;
* таймеры и список участников живут в RAM и сбрасываются после перезапуска —
  это ожидаемое поведение;
* бот не пишет пользователям в личку, только в тот чат, где вызвана команда.
